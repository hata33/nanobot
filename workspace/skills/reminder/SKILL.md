# 提醒 Skill

设置定时任务，在指定时间向用户发送提醒。

## 实现方式

使用内置 `cron` 工具：

```json
{
  "action": "add",
  "name": "每日早间提醒",
  "cron_expr": "0 9 * * *",
  "tz": "Asia/Shanghai",
  "message": "提醒：现在是早上 9 点，该开始工作了。"
}
```

## 规则

1. 提醒内容简洁，不超过 100 字
2. 支持一次性提醒（`at` 时间格式）和循环提醒（cron 表达式）
3. 重要提醒可以重复发送
4. 用户可以随时取消

## 触发条件

- "明天早上 8 点叫我"
- "每周一提醒我开会"
- "别让我忘了..."
