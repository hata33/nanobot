Pydantic Schema

Config 类使用 Pydantic 定义，支持 camelCase / snake_case 双格式键。JSON 用 camelCase，Python 用 snake_case，自动映射。

Pydantic camelCase snake_case
🔧

Config Loader

从 ~/.nanobot/config.json 加载配置，支持环境变量插值 ${ENV_VAR}。自动保存为 camelCase 格式。

JSON Env Interpolation Auto Save
📁

Path 管理

Config 驱动所有路径：workspace、sessions、memory、cron、webui、media、logs。支持自定义 workspace 位置。

Workspace Sessions Memory

配置路径

主配置文件默认位于 ~/.nanobot/config.json。支持通过 config_path 参数自定义位置。

~/.nanobot/config.json Custom Path

Workspace 路径

默认 ~/.nanobot/workspace/，可配置。会话、记忆、cron 任务均在此目录下。

~/.nanobot/workspace/ Customizable
