工具分类

Tool Categories

📁

文件系统工具

read_file / write_file / edit_file / list_dir / find_files。操作 workspace 内的文件，支持原子写入。

read_file write_file edit_file
💻

Shell 执行

exec 工具执行系统命令。支持本地 / Docker / Firecracker 沙箱，带安全策略与输出限制。

exec sandbox security
🌐

网络工具

web_search / web_fetch。支持搜索引擎调用、网页抓取，带 SSRF 防护与 URL 校验。

web_search web_fetch SSRF
🔌

MCP 工具

mcp_* 系列工具。通过 Model Context Protocol 接入外部服务，自动发现与调用 MCP Server 工具。

MCP Server Discovery
⏰

调度工具

cron 工具管理定时任务。支持创建、删除、列出 cron jobs，持久化到 workspace。

cron schedule persist
🤖

子代理与长任务

spawn 派发子代理，long_task 管理长时间运行的后台任务。支持并发与进度追踪。

spawn long_task subagent
📦

    TR->>TR: validate & cast params
    TR-->>AR: (tool, cast_params, error)
    AR->>BT: execute(cast_params, context)
    BT->>RC: access workspace/session
    BT-->>AR: tool_result
    AR->>AR: append to messages
📋

get_definitions()

返回稳定排序的工具 schema 列表。内置工具按字母排序在前，MCP 工具在后。缓存直到下次 register/unregister。

Schema Cache Stable Order
✅

prepare_call()

解析工具调用：查找工具、类型转换、参数校验。返回 (tool, cast_params, error) 三元组。

Resolve Validate Cast
