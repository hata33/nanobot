技术栈

Python + React + Async

🐍
Python 3.11+

核心运行时，全面使用 asyncio 异步框架。

  • asyncio 事件循环
  • Pydantic 配置校验
  • typer CLI 框架
⚛️
React + TypeScript

WebUI 前端，Vite 构建，WebSocket 实时通信。

  • React 18 + TypeScript
  • Vite 构建工具
  • WebSocket multiplex
🔮
MCP

Model Context Protocol，标准化工具接口。

  • stdio / HTTP / SSE
  • 自动工具发现
  • 多服务并发
🔄
消息队列

异步消息总线，解耦 Channel 与 Agent。

  • InboundMessage / OutboundMessage
  • 自动重试与错误处理
  • 多 Channel 并发
