核心模块详解

Core Modules Detail

🔄

agent/loop.py - AgentLoop

Agent 核心状态机。管理 turn 的完整生命周期：RESTORE → COMPACT → COMMAND → BUILD → RUN → SAVE → RESPOND → DONE。负责 session 加载、context 构建、tool 调度、outbound 发布。

State Machine TurnState Async
⚡

agent/runner.py - AgentRunner

LLM 对话执行循环。发送消息给 Provider，处理 tool_call，执行工具，回填结果，直到产生最终答案或达到迭代上限。支持 streaming、retry、injection。

LLM Loop Tool Execution Streaming
📡

bus/queue.py - MessageBus

异步消息队列，解耦 Channel 与 Agent。提供 inbound/outbound 双队列，Channel 只需 publish_inbound，Agent 只需 consume_inbound，互不依赖。

asyncio.Queue Pub/Sub Decouple
💾

session/manager.py - SessionManager

会话历史管理。JSONL 文件存储，原子写入，支持 TTL 压缩、fork、继续标记。近期对话与长期记忆分层持久化。

JSONL Atomic Write TTL Compact
🔧

agent/tools/ - ToolRegistry

工具注册与发现中心。BaseTool 抽象 + registry 模式，支持内置扫描与 entry point 插件。工具 schema 即模型契约。

Registry Plugin Schema
🔌

providers/ - LLM Provider

统一 LLM 后端抽象。LLMProvider 基类 + ProviderFactory + ProviderRegistry，支持 OpenAI/Anthropic/Azure/Bedrock/GitHub Copilot 等。

Abstract Factory Multi-Backend
🎯

Turn 状态机

8 个状态节点，通过事件驱动流转。每个状态职责单一，支持 hook 介入、进度回调、错误恢复。状态转移表定义在 _TRANSITIONS 字典中。

TurnState Event-Driven 8 States
⚡

LLM 执行循环

AgentRunner 的 run() 方法形成迭代循环：发送消息 → 接收 response → 检测 tool_call → 执行工具 → 回填结果 → 继续。支持 max_iterations 限制。

Iterative Tool Call Max Iterations
🔧

工具执行管线

ToolRegistry.prepare_call() 负责解析、校验、类型转换。RequestContext 注入 session/workspace/channel 等运行时信息。支持 concurrent_tools 并行执行。

Prepare Call RequestContext Concurrent
💬

Channel 渠道接入

BaseChannel 抽象 + ChannelManager 管理。支持 Telegram/Discord/Slack/Feishu/WeChat/WhatsApp 等 15+ 平台。自动发现 via pkgutil + entry points。

BaseChannel Auto-Discovery 15+ Platforms
🔌

Provider 模型后端

LLMProvider 统一接口，支持 OpenAI/Anthropic/Azure/Bedrock/GitHub Copilot/Codex/Ollama 等。ProviderFactory 按配置自动选择，FallbackProvider 支持故障转移。

LLMProvider Auto-Select Fallback
🌐

API / WebUI

OpenAI 兼容 API (/v1/chat/completions) 供外部调用。WebUI 通过 WebSocket 与 Gateway 通信，提供现代聊天界面。

OpenAI Compatible WebSocket React SPA
⚙️

Config 配置体系

Pydantic 配置模型，camelCase/snake_case 兼容。支持环境变量插值 ${ENV_VAR}。配置驱动 Provider/Channel/Tool 实例化。

Pydantic Env Interpolation Config-Driven
