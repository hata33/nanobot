内置渠道

Built-in Channels

💻

CLI

命令行交互模式。支持 streaming 输出、prompt_toolkit 历史、Markdown 渲染。

Typer Prompt Streaming
🖥️

WebSocket / WebUI

WebSocket 多路复用协议。承载聊天、媒体、进度、命令，前端 React SPA 通过 WS 通信。

WebSocket React Multiplex
✈️

Telegram

Telegram Bot API。支持 polling / webhook，消息格式转换，Markdown 渲染。

Bot API Polling Webhook
🎮

Discord

Discord Bot + Gateway。支持频道消息、DM、Slash 命令、交互式组件。

Gateway Slash Interactions
💼

Slack

Slack Bolt SDK。支持事件订阅、交互式组件、线程回复。

Bolt SDK Events Threads
🐦

Feishu / 飞书

飞书事件订阅。支持卡片消息、机器人对话、富文本渲染、媒体消息。

Event Sub Card Rich Text

Discovery Flow 
flowchart LR
    Start[启动] --> Scan[pkgutil 扫描]
    Start --> Entry[entry_points 插件]
    Scan --> Builtin[内置 Channels]
    Entry --> Plugin[第三方 Channels]
    Builtin --> Register[ChannelManager.register]
    Plugin --> Register
    Register --> Init[初始化 Channel]
    Init --> Start[channel.start()]
    Start --> Ready[等待外部事件]
