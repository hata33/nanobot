安全边界

Security Boundaries

📂

工作区访问控制

WorkspaceScopeResolver 限制工具只能访问授权路径。防止 Agent 越权读写系统文件。

WorkspaceScopeResolver Path Restriction 最小权限
💻

Shell 沙箱

exec 工具支持多种沙箱后端：Local（路径映射 + 输出遮蔽）、Docker（容器隔离）、Firecracker（微 VM）。

Docker Firecracker Local
🌐

网络边界

network.py 做 SSRF 防护。Web 工具校验目标 URL，防止内网探测、本地回环攻击。

SSRF URL Sanitization Private IP
🔑

PTH 保护

Python 启动时检查 PTH 文件，防止恶意 .pth 文件劫持导入路径，导致权限提升。

PTH Guard Import Security Startup
🏖️

Docker 沙箱

命令在独立容器中执行，限制 CPU/内存/网络。容器销毁后自动清理，不留痕迹。

Container Resource Limit Ephemeral
🖥️

Local 沙箱

本地执行但限制在 workspace 路径。使用路径映射和输出遮蔽，防止敏感信息泄露。

Path Mapping Output Filter Workspace
🔥

Firecracker

基于 Firecracker 的轻量级微 VM。比 Docker 更快的启动速度，更强的隔离性。

MicroVM Fast Boot Isolation
