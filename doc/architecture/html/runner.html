AgentRunSpec

单次执行配置。包含初始消息、工具注册表、模型名称、迭代限制、温度、max_tokens、workspace 路径等。

@dataclass Config Immutable
📊

AgentRunResult

执行结果。包含最终文本内容、消息历史、使用的工具列表、token 用量、停止原因、错误信息。

@dataclass Result Usage

    Error[Provider Error] --> Check{Retryable?}

    Backoff --> Retry[Retry Request]

🔄

重试策略

provider_retry_mode 控制重试行为。标准模式使用指数退避，支持超时、限流、服务端错误的自动重试。

Exponential Backoff Timeout Rate Limit
🔀

FallbackProvider

主 Provider 失败时自动切换到备用 Provider。支持多级 fallback，提升服务可用性。

Fallback Multi-Level HA
💬

用户友好提示

配额耗尽、账户欠费时返回 ARREARAGE_ERROR_MESSAGE。空结果重试超限时返回 EMPTY_FINAL_RESPONSE_MESSAGE。
