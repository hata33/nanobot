Fallback 策略

Fallback Strategy

Fallback Flow 
flowchart LR
    Request[LLM Request] --> Primary[Primary Provider]
    Primary -->|Success| Response[返回结果]
    Primary -->|Error| CheckRetry{可重试?}
    CheckRetry -->|yes| Retry[重试 Primary]
    CheckRetry -->|no| Fallback[FallbackProvider]
    Retry -->|成功| Response
    Retry -->|失败| Fallback
    Fallback --> Alt1[备用 Provider 1]
    Alt1 -->|失败| Alt2[备用 Provider 2]
    Alt2 -->|失败| Error[返回错误]
    Alt1 -->|成功| Response
    Alt2 -->|成功| Response

自动故障转移

FallbackProvider 包装主 Provider，失败时自动按顺序尝试备用 Provider。支持多级 fallback 配置。

Auto Failover Multi-Level Config-Driven
⚡

即时切换

无需修改业务代码，只需在配置中声明 fallback 列表。运行时自动检测主 Provider 健康状态。

Zero Code Health Check Runtime
