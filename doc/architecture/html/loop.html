📂

RESTORE

从 SessionManager 加载历史消息，恢复上下文状态。读取 JSONL 文件，解析消息列表。

SessionManagerJSONL
🗜️

COMPACT

上下文压缩。当消息数或 token 数超过阈值时，自动压缩旧消息，保留近期上下文。

AutoCompactTTL
⚡

COMMAND

检查斜杠命令。通过 CommandRouter 解析用户输入中的命令，短路执行或继续正常流程。

CommandRouterSlash
🔨

BUILD

构建完整上下文。ContextBuilder 组装 system prompt、历史消息、skills、memory 片段。

ContextBuilderPrompt
▶️

RUN

执行阶段。创建 AgentRunSpec，调用 AgentRunner.run()，启动 LLM 执行循环。

AgentRunnerLLM
💾

SAVE / RESPOND

SAVE：SessionManager.save_turn() 持久化本轮对话。RESPOND：通过 MessageBus 发布 outbound 消息。

SessionOutbound
🧩

ContextBuilder

组装完整上下文。合并 system prompt、历史消息、skills 定义、memory 片段，生成发送给 Provider 的 messages 列表。

build() System Prompt History
🪝

AgentHook

生命周期钩子系统。支持 before_run / after_run / on_tool / on_error 等钩子，CompositeHook 支持多钩子组合。

CompositeHook Lifecycle Extensible
📊

ProgressHook

进度回调。将 AgentRunner 的 streaming 增量转换为前端可展示的进度事件，支持实时渲染。

ProgressEvent Streaming Real-time
