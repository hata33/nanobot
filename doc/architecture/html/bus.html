InboundMessage

外部平台消息进入系统时的统一封装。包含 channel、chat_id、content、sender 等字段。

📁 nanobot/bus/queue.py
📤
OutboundMessage

Agent 生成回复后的统一封装。包含 channel、chat_id、text、attachments 等字段。

📁 nanobot/bus/queue.py
⚡
异步队列

基于 asyncio.Queue，支持多 Channel 并发接入。自动重试、错误隔离、背压控制。

📁 nanobot/bus/queue.py
🔌
Channel 解耦

Channel 只负责接入外部平台，不直接调用 Agent。通过消息总线交换 Inbound/Outbound 消息，实现彻底解耦。

📁 nanobot/channels/
