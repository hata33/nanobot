拓展能力目录

Extension Catalog

🛠️
自定义 Tool（工具）
简单
agent/tools/base.py → BaseTool
继承 BaseTool，实现 execute(args, context) 和 to_schema()。 工具会自动注册到 ToolRegistry，模型可以直接调用。
实现步骤：
1. 在 agent/tools/ 下新建 my_tool.py
2. 继承 BaseTool，实现 execute()
3. 通过 entry_points=[nanobot.tools] 或 pkgutil 自动发现
参考：agent/tools/filesystem.py、agent/tools/web.py
💬
自定义 Channel（渠道）
中等
channels/base.py → BaseChannel
继承 BaseChannel，实现 start()、stop()、send()。 通过 publish_inbound 接入消息总线。
实现步骤：
1. 在 channels/ 下新建 my_channel.py
2. 继承 BaseChannel，实现三个抽象方法
3. 配置 channels.myChannel.enabled = true
参考：channels/telegram.py、channels/websocket.py
🔌
自定义 Provider（模型后端）
中等
providers/base.py → LLMProvider
继承 LLMProvider，实现 chat() 和 stream()。 通过 ProviderFactory 按配置自动选择。
实现步骤：
1. 在 providers/ 下新建 my_provider.py
2. 继承 LLMProvider，实现 chat()
3. 在 registry.py 注册 Provider spec
4. 在 schema.py 添加配置字段
参考：providers/openai_compat_provider.py
📦
自定义 Skill（技能）
简单
skills/ → SKILL.md（Markdown）
写一个 SKILL.md 文件，描述技能的使用方法、工具调用方式。 Agent 会自动加载并学习该技能。
实现步骤：
1. 在 workspace/skills/my-skill/SKILL.md 创建技能
2. 写 YAML frontmatter（name, description）
3. 在 Markdown 中描述步骤和工具用法
参考：skills/github/SKILL.md、skills/cron/SKILL.md
⚡
自定义 Command（斜杠命令）
简单
command/router.py → CommandRouter
通过 CommandRouter 注册自定义斜杠命令， 实现 /mycommand 处理逻辑。
实现步骤：
1. 在 command/builtin.py 中注册命令
2. 或通过 CommandRouter.register() 动态注册
3. 处理函数接收 CommandContext，返回回复文本
参考：command/builtin.py 中的 /help、/clear
⏰
Cron Job（定时任务）
中等
cron/service.py → CronService
通过 CronService 创建定时任务，支持 at、every、cron 三种调度模式。 任务可以触发 Agent 执行特定动作。
实现步骤：
1. 通过 cron 工具创建任务：/cron add "every 1h" "message"
2. 或通过 API 编程创建 CronJob
3. 任务持久化到 workspace/cron/jobs.json
参考：agent/tools/cron.py、cron/service.py
🔌
MCP Server（外部服务接入）
中等
agent/tools/mcp.py → MCPTool
通过 Model Context Protocol 接入外部服务（数据库、API、文件系统等）。 MCP Server 独立运行，Agent 通过 mcp_* 工具调用。
实现步骤：
1. 启动 MCP Server（如 npx mcp-server-filesystem）
2. 在配置中添加 MCP server 连接
3. Agent 自动发现并使用 mcp_ 工具
参考：agent/tools/mcp.py、webui/mcp_presets_api.py
🤖
子代理派发（Sub-agent）
中等
agent/tools/spawn.py → spawn
通过 spawn 工具派发子 Agent 处理复杂任务。 支持并发执行、结果聚合、独立会话。
实现步骤：
1. Agent 自动使用 spawn 工具派发子任务
2. 或通过 long_task.py 创建长时间运行任务
3. 子 Agent 拥有独立的 AgentLoop 和 Session
参考：agent/tools/spawn.py、agent/tools/long_task.py
🎨
图片生成（Image Generation）
简单
providers/image_generation.py → ImageGenerationProvider
通过 ImageGenerationProvider 接入图片生成服务（OpenAI DALL-E、Gemini、Ollama 等）。 Agent 可以通过 generate_image 工具调用。
实现步骤：
1. 配置图片生成 Provider（如 OpenAI）
2. Agent 自动获得 generate_image 工具
3. 或注册自定义 ImageGenerationProvider
参考：providers/image_generation.py
🎙️
音频转写（Audio Transcription）
简单
audio/transcription.py → TranscriptionProvider
通过 Whisper（OpenAI / Groq）将语音消息转写为文本。 微信、Telegram 等渠道的语音消息会自动转写。
实现步骤：
1. 配置 OpenAI 或 Groq API Key
2. 语音消息自动触发转写流程
3. 转写结果注入对话上下文
参考：audio/transcription.py、channels/weixin.py` 中的 transcribe_audio()
🪝
Hook 中间件（生命周期扩展）
中等
agent/hook.py → AgentHook
通过 AgentHook 介入 Agent 执行生命周期， 实现日志、审计、进度追踪、重试策略等横切逻辑。
实现步骤：
1. 继承 AgentHook，实现 before_run、after_run、on_tool 等
2. 通过 CompositeHook 组合多个 Hook
3. 在 AgentRunSpec 中注入 Hook
参考：agent/hook.py、agent/progress_hook.py
🖥️
WebUI 前端扩展
困难
webui/ → React/TypeScript SPA
WebUI 基于 React + TypeScript + Vite 构建， 通过 WebSocket 与 Gateway 通信。可以扩展页面、组件、API 路由。
实现步骤：
1. 修改 webui/src/ 下的 React 组件
2. 在 webui/gateway_services.py 添加后端 API
3. 运行 bun run dev 启动开发服务器
参考：webui/gateway_services.py、webui/workspaces.py
