自定义 Tool
简单

继承 BaseTool，实现 execute 和 to_schema。自动注册到 ToolRegistry。

  • 文件系统工具已内置
  • Shell 执行受沙箱控制
  • Web 搜索/抓取可用
📁 nanobot/agent/tools/

自定义 Channel
中等

继承 BaseChannel，实现 start/stop/send。外部平台消息转成 InboundMessage 送进消息总线。

  • Telegram、Discord、Slack 等已内置
  • 支持自动发现 + 插件
  • 需处理配对/审批逻辑
📁 nanobot/channels/

🎯
新手起步

先写几个 Skill，比如：

  • psych-support - 心理陪伴
  • weather-reporter - 天气查询
  • market-watcher - 美股行情

这些只需写 Markdown，不需要改代码，立刻能看到效果。

🔧
进阶开发

当 Skill 不够用时，开始写 Tool：

  • 封装 Python 库为工具
  • 接入新的 API 服务
  • 实现自定义数据处理

Tool 可以访问文件系统、网络、shell，能力边界更大。

🏗️
深度定制

需要改核心架构时：

  • Channel：接入新的聊天平台
  • Provider：接入新的 LLM 后端
  • Hook：修改 Agent 核心行为
  • WebUI：定制界面体验

这些需要理解核心代码，改动影响面大，建议先阅读源码。
