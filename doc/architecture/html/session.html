    SM->>S: append message

    FS-->>SM: success

    Note over SM,FS: TTL / 消息数超限时
    SM->>SM: compact()
    SM->>FS: archive old messages
📝

JSONL 存储

会话历史以 JSONL 格式存储，每行一条消息。支持原子写入（write + fsync），避免断电丢失。

JSONL Atomic Write fsync
🗜️

TTL 压缩

当消息数超过阈值或 TTL 到期时，自动压缩旧消息。保留近期 N 条，归档历史到独立文件。

Auto Compact TTL Archive
🍴

Fork 支持

fork 操作复制会话历史，保留可变的运行时元数据（title、goal_state）与不变的历史消息。

Fork Copy Metadata
📡

Session Key

session_key 由 channel + chat_id 生成（如 telegram:12345）。统一会话键支持跨渠道会话聚合。

session_key_for_channel UNIFIED_SESSION_KEY
🎯

Goal State

长期目标状态追踪。记录 sustained goal 的启动时间、超时、延续标记，支持 Agent 跨 turn 持续执行。

sustained_goal_active wall_clock_timeout
